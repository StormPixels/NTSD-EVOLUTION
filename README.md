# NTSD Evolution

The first alpha release of NTSD Evolution, developed and modified by StormPixels.

## About

NTSD Evolution is a fan-made Naruto fighting game project based on a modified F.L.F / Project-F engine.

This project aims to improve and expand the original game with modifications and new features.

## Current Version

- **Version:** Alpha 0.0.1
- **Development Status:** Early Alpha
- **Developer:** StormPixels

## Known Issues

- This project is still in early alpha development.
- Many bugs and glitches are expected.
- Some features may be incomplete or not work as intended.
- Gameplay, performance, and stability may change in future updates.

**Note:** This is an early development build. Please expect bugs and unfinished features.
