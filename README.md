# NTSD Evolution

The first alpha release of NTSD Evolution, developed and modified by StormPixels.

## About
A fan-made Naruto fighting game project based on a modified F.LF / Project-F engine.

## Known Issues
- This project is still in early alpha development.
- Bugs and incomplete features are expected.

## Installation
Download the ZIP file attached to this release and extract it while preserving the original folder structure.

A YouTube installation tutorial will be added later.
