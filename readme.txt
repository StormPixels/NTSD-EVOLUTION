NTSD EVOLUTION
Version Alpha 0.0.1
Project Information
===================

ABOUT THE PROJECT
-----------------
NTSD Evolution is a fan-made project intended to make a Naruto: The Setting Dawn
(NTSD)-style game playable on as many devices as possible through a compatible
web browser.

This project is developed by StormPixels. It is built on the F.LF / Project-F
engine, which has been modified by StormPixels for this project.

CURRENT VERSION
---------------
Version: Alpha 0.0.1

This project is still in its very early development stage and contains many
bugs, unfinished features, and other issues. Gameplay may be unstable, and
some features may not work as intended.

Please keep this in mind when testing the project. Feedback, bug reports, and
suggestions are always welcome and can help improve future versions.

DEVELOPMENT
-----------
This project is developed entirely on a mobile phone, with assistance from AI
tools. The long-term goal is to improve the project until it becomes a fully
playable browser game across different devices.

ASSETS AND DESIGN
-----------------
The project uses assets from NTSD 2.6, along with some assets and content
created by StormPixels. Some menu and visual design elements are inspired by
John Muffin's work.

Credits and ownership for third-party assets remain with their respective
owners. Please respect the original creators' rights and applicable licenses.

ENGINE
------
NTSD Evolution is based on F.LF / Project-F, modified by StormPixels.

Anyone interested in learning more about the engine or developing their own
project can visit the official Project-F resources.

PROJECT GOAL
------------
The goal is to make NTSD accessible through a web browser on mobile devices,
computers, and other compatible platforms.

This is an independent fan project and is not an official NTSD release.
